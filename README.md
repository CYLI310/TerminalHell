# Terminal Velocity

A fast-paced, terminal-based bullet hell game where you must dodge waves of incoming projectiles to survive.

## How to Play

- **WASD / Arrow Keys**: Move your character.
- **Space / 1**: Select menu items.
- **Q**: Quit the game or return to the main menu.

## Levels

1.  **The Beginning**: Dodge the falling debris.
2.  **Crossfire**: Bullets are coming from the sides!
3.  **The Storm**: Watch out for the diagonal bursts.
4.  **Circle of Death**: Explosive patterns everywhere.
5.  **The Spiral**: Vortex of death.
6.  **Final Frontier**: Everything together.
